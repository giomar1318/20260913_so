# 한글 놀이터

유치원 아이들이 한글을 놀이처럼 익힐 수 있도록 만든 웹 학습 앱입니다.  
글자를 보고, 소리로 듣고, 손으로 따라 쓰고, 간단한 문제를 풀면서 자음과 모음을 자연스럽게 학습할 수 있습니다.

## 서비스 바로가기

[한글 놀이터 열기](https://hangul-playground-kids.giomar.chatgpt.site)

현재 서비스는 비공개로 게시되어 있어 처음 접속할 때 ChatGPT 로그인이 필요할 수 있습니다.

## 주요 학습 내용

- 자음 14개
- 모음 10개
- 쌍자음 5개
- 쌍모음 11개

## 주요 기능

### 1. 글자 익히기

자음, 모음, 쌍자음, 쌍모음 중 원하는 종류를 선택할 수 있습니다.  
글자를 누르면 글자 이름과 관련 낱말을 캐릭터 목소리로 들려줍니다.

### 2. 읽기 놀이

그림을 보고 알맞은 낱말을 고르는 게임입니다.  
정답을 맞히면 별을 받고, 정답과 낱말의 소리를 다시 들을 수 있습니다.

### 3. 쓰기 놀이

화면의 점선 글자를 따라 손가락이나 마우스로 직접 써볼 수 있습니다.  
`다시 쓰기` 버튼으로 지우거나 `다 썼어요` 버튼으로 쓰기를 완료할 수 있습니다.

### 4. 듣기 놀이

캐릭터 목소리로 들려주는 글자를 듣고 세 개의 보기 중 정답을 고르는 게임입니다.

### 5. 별 모으기

읽기, 쓰기, 듣기 활동을 완료하면 별을 받을 수 있습니다.  
모은 별은 브라우저에 저장되므로 같은 기기와 브라우저에서 다시 접속하면 유지됩니다.

## 디자인 특징

- 귀여운 꼬마 로봇 캐릭터 테마
- 연필을 든 로봇 모양의 마우스 커서
- 아이들이 알아보기 쉬운 크고 단순한 버튼
- PC와 휴대폰 화면에 맞게 변하는 반응형 디자인
- 한글 가독성이 좋은 프리텐다드 폰트 사용
- 움직임을 줄이도록 설정한 기기에서는 애니메이션 자동 최소화

## 캐릭터 목소리

브라우저의 한국어 음성 읽기 기능을 사용합니다.  
아이들이 듣기 편하도록 일반 음성보다 밝고 높은 톤과 조금 느린 속도로 설정했습니다.

사용하는 휴대폰, PC, 운영체제에 따라 실제 목소리는 조금 다르게 들릴 수 있습니다. 기기에 한국어 음성이 없거나 브라우저가 음성 읽기를 지원하지 않으면 소리가 나오지 않을 수 있습니다.

## 사용 기술

- HTML: 화면의 내용과 구조
- CSS: 색상, 배치, 캐릭터 테마와 반응형 디자인
- JavaScript: 음성 재생, 문제 출제, 정답 확인, 쓰기 기능과 별 저장
- Web Speech API: 브라우저의 한국어 음성 읽기 기능
- Canvas API: 마우스와 손가락으로 글자를 쓰는 기능
- Local Storage: 모은 별을 브라우저에 저장하는 기능

별도의 프레임워크나 데이터베이스 없이 HTML, CSS, JavaScript만으로 제작했습니다.

## 파일 구조

```text
20260913-so/
├─ README.md
├─ .openai/
│  └─ hosting.json
└─ dist/
   ├─ index.html
   ├─ styles.css
   ├─ script.js
   └─ assets/
```

- `dist/index.html`: 앱 화면의 기본 구조
- `dist/styles.css`: 디자인과 모바일 화면 설정
- `dist/script.js`: 학습 게임과 음성 기능
- `.openai/hosting.json`: 웹사이트 게시 설정

## 실행 방법

가장 간단한 방법은 `dist` 폴더 안의 `index.html` 파일을 더블클릭하여 브라우저로 여는 것입니다.

음성 기능이 제한되거나 파일이 제대로 표시되지 않는 경우에는 VS Code의 Live Server와 같은 로컬 웹 서버를 사용해 `dist` 폴더를 실행해 주세요.

## 권장 사용 환경

- 최신 버전의 Chrome, Edge, Safari
- 소리를 들을 수 있는 스피커 또는 이어폰
- 쓰기 놀이를 위한 마우스 또는 터치 화면

아이들이 사용할 때는 보호자가 기기의 음량을 먼저 확인해 주세요.
